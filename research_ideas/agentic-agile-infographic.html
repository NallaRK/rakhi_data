Section 03A — How It Works

The Release Sync Pipeline

7 steps — from code change to fully synchronized central Knowledge Base. Triggered only when a release tag is published.

🔍
Delta Generation
# Get changed files
git diff v1..HEAD
  --name-only
  | grep -E '.ts|.java'
  | repomix --stdin
🤖
Local Copilot Reconcile
Copilot Edits analyzes the packed delta XML and surgically updates only changed sections in copilot-instructions.md and product-capabilities.md. No full rewrites.
⚙️
GitHub Action (Free)
sync-release-kb.yml triggers on tag push. Checks out both repos, copies files, opens a PR on the central KB. Requires only a fine-grained PAT — no LLM keys.
🐍
Matrix Auto-Rebuild
On PR merge, rebuild-domain-matrix.yml runs a Python parser that aggregates all product/capabilities/*.md files into the Master Domain Matrix table — automatically committed to main.
Section 03B — Setup

Cold-Start Setup Guide

Three distinct phases to go from zero to a fully operational Agentic Agile Knowledge Base across your entire repo ecosystem.

🏗️
Phase 1: Bootstrap
One-time · Architects
1 Create mfe-knowledge-base repo with product/ and engineering/ dirs
2 Run bootstrap-agentic-agile.py in each Spoke — auto-detects stack, scaffolds all Copilot instruction files
3 Deploy sync-release-kb.yml to every Spoke repo; store ORGANIZATION_KB_SYNC_TOKEN as org secret
4 Deploy rebuild-domain-matrix.yml to central KB with contents:write permission
✍️
Phase 2: Initial Content
Per-repo · Dev Lead
1 Open vantage-workspace.code-workspace — links all Spoke repos + Central KB in one VS Code window
2 Switch to Copilot Edits Ctrl+Shift+Alt+I; add empty KB files to Working Set
3 Run Cold-Start Prompt with @workspace — Copilot generates capabilities and contracts from codebase
4 Review inline diffs → Accept → Commit → Push to main. Matrix auto-compiles on merge.
🔄
Phase 3: Ongoing Cadence
Per-release · Dev Lead + Arch
1 Generate release delta: git diff v1..HEAD | repomix --stdin — pack only changed structural files
2 Run /reconcile-release in Copilot Edits — surgically updates only affected sections
3 Accept → Commit docs → Push release tag. GitHub Action fires automatically, copies files, opens KB PR
4 Lead Architect merges PR → Python aggregator auto-rebuilds Master Domain Matrix ✓
Section 03C — Prevention

Drift Prevention Alternatives

Shift documentation alignment from post-hoc detection to proactive prevention. Three strategies — choose by team maturity.

🖥️
Pre-commit Gate
Husky + lint-staged
LOCAL
Aborts git commit if a Redux slice changes without a matching update to copilot-instructions.md — catches drift before it leaves the machine.
✓Zero latency — local enforcement
✓No CI/CD costs or dependencies
✓Simple npm install setup
⚠Can be bypassed with --no-verify
Best for: Teams with strong discipline wanting minimal tooling overhead
🤖
RepoAgent Auto-Sync
AI-powered · Local LLM
AUTO
Fully automated — RepoAgent detects code changes during commit, calls a local/private LLM, and directly updates markdown contracts. Docs committed atomically with code.
✓Zero developer effort required
✓Supports private/local LLMs
✓Atomic code + doc commits
⚠Requires RepoAgent + LLM per dev
Best for: Teams wanting maximum automation with zero manual steps
🔌
Bi-directional Contracts
Pact / Specmatic
GOLD STD
Validates React MFE API calls against Spring Boot OpenAPI schema via a local Specmatic mock server. Breaking changes fail the MFE test suite at compile time — no text comparison needed.
✓Structural schema validation
✓Breaking changes caught at compile
⚠Requires OpenAPI-first discipline
Best for: Mature teams wanting true structural contract enforcement

Core Architectural Principles
🧠Bifurcated Truth — Product and Engineering domains separated by design; no cross-contamination of concerns.
🏷️Release-Gated Cadence — Docs tied to version boundaries, not individual PRs. Zero noise, guaranteed accuracy per release.
🔒Mechanically Enforced — Self-updating instructions, automated GitHub Actions, and Git hooks remove human discipline as a single point of failure.
📡Topological Propagation — Kahn's DAG algorithm ensures low-level contract changes cascade correctly to all dependent high-level components.
🔧Prevention over Detection — Shift-left strategy: pre-commit hooks, RepoAgent, and contract testing prevent drift before code is merged.
